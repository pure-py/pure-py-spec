\begin{abstract}
\replaced{Scientific results are increasingly computed by programs generated by AI coding tools, which favour Python. Such programs need assurance that they work as intended, and a formal specification against which
to check them is rarely available. \PurePy is a statically typed, immutable subset of Python with a formal
static and dynamic semantics, so that generated programs have a checkable meaning. Every well-formed \PurePy
program is a valid Python program, and the semantics is designed so that every run given a result by \PurePy
produces the same result under Python. A \PurePy program therefore runs unchanged under a standard Python
interpreter and under any implementation conforming to the \PurePy specification. This paper specifies
\PurePy as a versioned standard, with a formal grammar, a type system that accepts only programs accepted by
mypy and an operational semantics. A reference checker decides well-formedness, and a conformance suite tests
agreement with Python on CPython, GraalPy and Pyodide. An evaluation compares code generation by language
models into \PurePy with generation into Python and OCaml. Two research languages for scientific computing
compiled to \PurePy show its use as a foundation for language research.}{\PurePy is a pure, side-effect-free subset of Python: a functional language whose programs are referentially
transparent, reproducible, and easy to reason about, yet remain ordinary Python. Every well-formed \PurePy
program is valid Python, and where \PurePy gives a run a result, Python gives the same one, so the same source
runs under a standard Python interpreter and under any conforming implementation. This paper specifies \PurePy as a versioned standard, with a
formal grammar, a type system that accepts only programs accepted by mypy, and an operational semantics
that agrees with Python on every run it defines. A reference checker decides well-formedness, and a conformance test suite is exercised on CPython, GraalPy, and Pyodide. Aimed first at researchers in programming languages and pedagogy, \PurePy
is intended to grow into a common language for scientific computing, supporting portable applications in
modelling, data processing, analysis, and visualisation. }
\end{abstract}
