\subsection{Properties}
\label{sec:properties}

A value is well-formed at a context entry (\figref{well-formed-env}): ordinary values at
$\statusDefAssigned$, module references and class entries at the corresponding entry. An environment is
well-formed at a context that binds its variables at corresponding entries. The predefined environments
are well-formed at their contexts, and loading preserves well-formedness; these are the base case and the
module case of a soundness result for well-formedness, which remains to be established.

\begin{lemma}[Predefined environments]
\label{lem:predefined}
For each predefined module $q$ with $\mathcal{P}(q) = (\rho, \Gamma)$, $\vdash \rho : \Gamma$.
\end{lemma}
\begin{proof}
By inspection of \figref{predefined}: each member is bound to an ordinary value, and $\Gamma$ binds it at
$\statusDefAssigned$.
\end{proof}

\begin{theorem}[Load preservation]
\label{thm:load-preservation}
If $\vdash_{\mathsf{load}} q : \Gamma$ and $q \Rightarrow_{\mathsf{load}} \val{\rho}$ then $\vdash \rho : \Gamma$.
\end{theorem}
