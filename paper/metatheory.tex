\subsection{Metatheory}
\label{sec:metatheory}

\figref{well-formed-env} defines when a value is well-formed at a context entry: an ordinary value at
$\statusDefAssigned$, a module or class value at the matching module or class entry. An environment is
well-formed in a context that binds its variables at such entries. The predefined environments are
well-formed and loading preserves well-formedness, the base case and the module case of soundness.

\begin{lemma}[Predefined environments]
\label{lem:predefined}
For each predefined module $q$ with $\mathcal{P}(q) = (\rho, \Gamma)$, $\vdash \rho : \Gamma$.
\end{lemma}
\begin{proof}
By inspection of \figref{predefined}: each member is bound to an ordinary value, and $\Gamma$ binds it at
$\statusDefAssigned$.
\end{proof}

\begin{theorem}[Load preservation]
\label{thm:load-preservation}
If $\vdash_{\mathsf{load}} q : \Gamma$ and $q \Rightarrow_{\mathsf{load}} \val{\rho}$ then $\vdash \rho : \Gamma$.
\end{theorem}
