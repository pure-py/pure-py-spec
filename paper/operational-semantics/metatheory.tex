\subsection{Metatheory}
\label{sec:metatheory}

\figref{well-formed-env} defines when a value is well-formed at a context entry: an ordinary value at
$\statusDefAssigned$, a module or class value at the matching module or class entry. An environment is
well-formed in a context that binds its variables at such context entries. The predefined environments are
well-formed by construction, and a module loads to an environment that is well-formed at its signature.

\begin{theorem}[Loaded environments are well-formed]
\label{thm:loaded}
Write $\Gamma_{\mathcal{P}}$ for the context binding every predefined member.
If $\vdash_{\mathsf{load}} q : \Gamma$ then $\Gamma_{\mathcal{P}} \override \Gamma \vdash \tau$ for every
type $\tau$ in an entry of $\Gamma$.
If $\mathcal{P}(q) = (\rho, \Gamma)$ then $\vdash \rho : \Gamma$.
If $\vdash_{\mathsf{load}} q : \Gamma$ and $q \Rightarrow_{\mathsf{load}} \val{\rho}$ then $\vdash \rho : \Gamma$.
\end{theorem}
