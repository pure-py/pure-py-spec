\begin{AddedBlock}
For example, two lists holding the same \pyinline{nan} are compared element by element:
\end{AddedBlock}

\begin{python}
x: float = 1e400 - 1e400  # nan
print([1.0, x] == [2.0, x])  # False, decided at the first element
print([1.0, x] == [1.0, x])  # undef: nan against nan
\end{python}

\begin{AddedBlock}
\noindent Python gives \pyinline{True} for the second comparison, because it compares container elements by
identity before equality, a distinction that \PurePy does not make. Because the order of comparison is observable,
dictionaries are compared in the key order of the left operand. The meanings of all the operators are given in \specification.
\end{AddedBlock}
