## Writing conventions

Before writing prose, code, commits, issues or pull requests, load the `conventions:technical-authoring`,
`conventions:coding-conventions` and `conventions:github` skills, from the `conventions@fluid-org` plugin
([fluid-org/claude-plugins](https://github.com/fluid-org/claude-plugins)), which Claude Code offers to
install when the project is opened; load `conventions:spec-implementor` as well when working on the
reference checker.
