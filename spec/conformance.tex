Python means Python 3.12 throughout. \secref{syntax} gives the abstract syntax; the lexical syntax is
that of Python (\secref{lexical}). \secref{well-formedness} defines well-formedness, the static part of
the definition, and \secref{operational-semantics} the operational semantics, which is defined for well-formed programs.
A run is \emph{valid} when the semantics assigns it a result; any other run reaches an operation the
semantics leaves undefined.
