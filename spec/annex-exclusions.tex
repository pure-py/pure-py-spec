\chapter{Excluded Python behaviours (informative)}
\label{sec:exclusions}

the syntax, well-formedness rules or semantics of \PurePy, and their classification follows from
\secref{excluded-features}}. It summarises the Python behaviours excluded by \PurePy{}\added{ by design
(\secref{excluded-by-design})} and the stage at which each
exclusion takes effect\added{, and lists the common Python features excluded from this version
