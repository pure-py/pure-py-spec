\begin{definition}[Context]
\label{def:context}
A context $\Gamma$ (or $\Delta$) is a finite map from variables to \emph{context entries} $\theta$
(\figref{context-entries}). We write $\Gamma, \bind{x}{\theta}$ for $\Gamma$ with its entry for $x$ replaced by $\theta$,
$\dom(\Gamma)$ for the set of variables with an entry in $\Gamma$, and $\varnothing$ for the empty context.
\end{definition}
