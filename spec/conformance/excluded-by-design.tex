\subsection{\added{Python features excluded by design}}
\label{sec:excluded-by-design}

\begin{AddedBlock}
A syntactically valid Python program may use a \emph{feature outside \PurePy}: a form of Python syntax which is not
in the grammar of \secref{syntax}, or is in the grammar only at some positions or in some forms, or a built-in
function, standard library module, member of a predefined module or method of a built-in type which is not predefined
(\secref{modules-programs}). Each feature outside \PurePy is either \emph{excluded by design}, if it is listed in
\figref{excluded-by-design}, or otherwise \emph{not yet specified}, and so may be included in a later release. The
figure groups the features excluded by design by the reason for their exclusion, and \figref{not-yet-specified} in
the informative \annexref{exclusions} lists the common features not yet specified.
\end{AddedBlock}
