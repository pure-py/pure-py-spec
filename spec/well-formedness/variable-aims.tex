\Added{The rules for variables serve two aims: that a program has no mutable state\paperonly{ (\secref{no-mutable-state})},
so a variable never changes value, and that a well-typed program is also well typed under mypy. Within these
limits the rules permit as much as possible. For the first aim, a variable is introduced by a declaration,
parameter, import, pattern or generator, and is assigned at most once, either in its declaration or afterwards; an
assignment never introduces a variable and never reassigns one.}
