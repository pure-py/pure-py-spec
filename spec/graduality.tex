\section{Graduality}
\label{sec:graduality}

\figref{graduality-precision} gives the gradual types. Define $\TypeSet$ to be the set of
types, as given in \specification, and $\GTypeSet$ to be the set
of gradual types; $\sigma$ and $\tau$ range over $\TypeSet$, and $\gty{\sigma}$ and $\gty{\tau}$ over
$\GTypeSet$. Concretisation and abstraction are from \citet{garcia2016}; precision is from
\citet{siek2015}.

\input{spec/fig/graduality-precision}

\begin{definition}[Precision]
\label{def:precision}
Precision $\precTy$, a partial order on gradual types, is defined in \figref{graduality-precision}.
\end{definition}

\begin{lemma}[Discreteness of static types]
\label{lem:static-discrete}
If $\sigma \precTy \tau$ then $\sigma = \tau$.
\end{lemma}

\begin{definition}[Concretisation]
\label{def:concretisation}
Concretisation $\gamma : \GTypeSet \to \powersetplus{\TypeSet}$ is defined in \figref{graduality-concretisation}.
\end{definition}

\input{spec/fig/graduality-concretisation}

\begin{lemma}[Preservation and reflection of precision]
\label{lem:precision-concretisation}
$\gty{\sigma} \precTy \gty{\tau}$ if and only if $\gamma(\gty{\sigma}) \subseteq \gamma(\gty{\tau})$.
\end{lemma}

A gradual type $\gty{\tau}$ \emph{approximates} a set $S$ of types when $S \subseteq \gamma(\gty{\tau})$;
$\tyAny$ approximates every set of types. A least approximant is a best abstraction in the sense
of \citet{cousot1977}. Preservation is monotonicity of concretisation. Reflection forces every
approximant of $S$ to lie above the join of $S$, so the join is the least approximant; without
reflection it would approximate $S$ but need not be least.

\begin{lemma}[Least approximant]
\label{lem:least-approximant}
For every nonempty set $S$ of types, the least upper bound $\bigsqcup S$ under $\precTy$ exists and
is the least $\gty{\tau}$ that approximates $S$.
\end{lemma}

\begin{proof}
Since $\gamma(\sigma) = \set{\sigma}$ for every type $\sigma$, approximating $S$ is the same as
bounding $S$ above under $\precTy$ (Lemma~\ref{lem:precision-concretisation}). The join of two
gradual types (\figref{graduality-join}) is their least upper bound, by induction on the pair, so
every finite nonempty set of gradual types has a least upper bound, by induction on its size. Fix
$\sigma \in S$. The gradual types above $\sigma$ are obtained by replacing subterms of $\sigma$ with
$\tyAny$, so there are finitely many; the joins $\bigsqcup F$ for finite $F \subseteq S$ containing
$\sigma$ lie among them and increase with $F$, so some $\bigsqcup F$ is maximal. Then
$\tau \precTy \bigsqcup (F \cup \set{\tau}) = \bigsqcup F$ for every $\tau \in S$ by maximality, so
$\bigsqcup F$ bounds $S$; and every bound of $S$ bounds $F$, so $\bigsqcup F$ is least.
\end{proof}

\input{spec/fig/graduality-join}

\begin{definition}[Abstraction]
\label{def:abstraction}
Abstraction $\alpha : \powersetplus{\TypeSet} \to \GTypeSet$ is defined by
$\alpha(S) = \bigsqcup S$ (Lemma~\ref{lem:least-approximant}).
\end{definition}

\noindent Every gradual type approximates the empty set, and $\GTypeSet$ has no least element under
$\precTy$, so the empty set is excluded from the domain of $\alpha$. Concretisation and abstraction
form a \emph{Galois insertion}: $\alpha(S) \precTy \gty{\tau}$ if and only if
$S \subseteq \gamma(\gty{\tau})$ (Lemma~\ref{lem:least-approximant}), and
$\alpha(\gamma(\gty{\tau})) = \gty{\tau}$ by reflection
(Lemma~\ref{lem:precision-concretisation}).

A relation on types lifts to gradual types through concretisation \citep{garcia2016}: the lifted
relation holds when the concretisations contain a related pair. A conjunction of such statements
lifts in the same way, with one witness for each type it mentions. Subtyping and equivalence on
types are as defined in \specification; equivalence lifts to \emph{consistency}.

\begin{definition}[Consistency]
\label{def:consistency}
$\Sigma \vdash \gty{\sigma} \gtyEquiv \gty{\tau}$ if and only if $\Sigma \vdash \sigma \tyEquiv \tau$ for some
$\sigma \in \gamma(\gty{\sigma})$ and $\tau \in \gamma(\gty{\tau})$.
\end{definition}

\begin{definition}[Lifted conjunctions]
\label{def:lifted-conjunctions}
$\Sigma \vdash \jointSub{\gty{\tau}}{\gty{\sigma}}{\gty{\tau}'}$ if and only if
$\Sigma \vdash \tau \subty \sigma$ and $\Sigma \vdash \tau' \subty \sigma$ for some
$\tau \in \gamma(\gty{\tau})$, $\tau' \in \gamma(\gty{\tau}')$ and
$\sigma \in \gamma(\gty{\sigma})$; likewise
$\jointEquiv{\gty{\tau}}{\gty{\sigma}}{\gty{\tau}'}$, over equivalence, and
$\jointSup{\gty{\tau}}{\gty{\sigma}}{\gty{\tau}'}$, over the converse of subtyping.
\end{definition}

\noindent A judgement of this form holds exactly when its reversal holds, and implies each
conjunct; the converse fails, because separately lifted conjuncts take their witnesses
independently.

\figref{graduality-subtyping} defines \emph{consistent subtyping} by lifting the subtyping rules
of \specification: types become gradual types, subtyping premises become consistent subtyping,
equivalence premises become consistency, and two axioms place $\tyAny$ below and above every
gradual type. The premises of \ruleName{gsubty-union} share their right-hand type, so they lift
jointly to $\jointSub{\gty{\tau}}{\gty{\sigma}}{\gty{\tau}'}$, which matches the lifting of
their conjunction by construction, because a concrete union lies below $\sigma$ exactly when both
components do. Lifting them separately would derive
$\Sigma \vdash \tyUnion{\tyList{\tyInt}}{\tyList{\tyStr}} \gsubty \tyList{\tyAny}$, since
$\tyInt \gtyEquiv \tyAny$ and $\tyStr \gtyEquiv \tyAny$; but
$\gamma(\tyList{\tyAny}) = \set{\tyList{\tau} \mid \tau \in \TypeSet}$, and
$\Sigma \vdash \tyUnion{\tyList{\tyInt}}{\tyList{\tyStr}} \subty \tyList{\tau}$ requires
$\tyInt \tyEquiv \tau$ and $\tyStr \tyEquiv \tau$. The intended characterisation is the
lifting of subtyping itself; the rules satisfy one direction.

\input{spec/fig/graduality-subtyping}

\begin{lemma}[Completeness of the lifted rules]
\label{lem:consistent-subtyping-complete}
If $\Sigma \vdash \sigma \subty \tau$ for some $\sigma \in \gamma(\gty{\sigma})$ and
$\tau \in \gamma(\gty{\tau})$ then $\Sigma \vdash \gty{\sigma} \gsubty \gty{\tau}$.
\end{lemma}

An inductive characterisation of $\jointSub{\gty{\tau}}{\gty{\sigma}}{\gty{\tau}'}$ can be extracted from a decidability proof: each case
of the induction either exhibits witnesses or refutes their existence, and the positive cases,
read as inference rules, give \figref{graduality-joint-sub}. The proof is a device for finding
the rules; the surviving obligation, that the rules derive the judgement exactly, follows from
the same case analysis, because every positive case is an equivalence.

\begin{lemma}[Decidability]
\label{lem:joint-sub-decidable}
The judgement $\Sigma \vdash \jointSub{\gty{\tau}}{\gty{\sigma}}{\gty{\tau}'}$ of
Definition~\ref{def:lifted-conjunctions} is decidable.
\end{lemma}

\begin{proof}[Proof sketch]
By induction on the triple, ordered by the total size of the three types and then by the size of
the first; cases on the triple. An outer type $\tyAny$ or $\tyNever$ takes the witness $\tyNever$,
leaving a consistent subtyping check on the other outer type (\ruleName{joint-sub-any-left},
\ruleName{joint-sub-never-left}). A union in an outer position reassociates, because its witness is a union,
below $\sigma$ exactly when both components are (\ruleName{joint-sub-assoc}). Otherwise both outer
witnesses are constructor-headed. In the middle, $\tyAny$ admits the witness $\tyObject$
(\ruleName{joint-sub-any}). A static middle type is its own sole concretisation, so sharing is
trivial and two consistent subtyping checks remain (\ruleName{joint-sub-static}). For a union in
the middle, inversion sends each outer witness into one component: the same component
(\ruleName{joint-sub-union-left}, \ruleName{joint-sub-union-right}), or different components, in
which case the witnesses no longer interact (\ruleName{joint-sub-split}). A constructor in the
middle must head both outer types, or the case refutes. Tuples proceed componentwise
(\ruleName{joint-sub-tuple}); lists and dictionaries need one element witness equivalent to both
element types (\ruleName{joint-sub-list}, \ruleName{joint-sub-dict}), and callable arguments one
witness below both argument types (\ruleName{joint-sub-callable}), the other two judgements of
Definition~\ref{def:lifted-conjunctions}. Each appeal to the hypothesis decreases the order.
\end{proof}

\subsection{Rules for $\jointSup{\gty{\tau}}{\gty{\sigma}}{\gty{\tau}'}$}

The rules of \figref{graduality-joint-sub} appeal at callable arguments to judgements of the form
$\jointSup{\gty{\tau}}{\gty{\sigma}}{\gty{\tau}'}$, in which the middle witness lies below the
outer witnesses, so the method must be repeated for them. The case analysis closes every case
but one; the positive cases give \figref{graduality-joint-sup}.

The induction is on the total size of the triple; cases as before. In the middle, $\tyAny$
admits the witness $\tyNever$, below every type (\ruleName{joint-sup-any}); a static middle type
is its own sole concretisation, so sharing is trivial and two consistent subtyping checks remain
(\ruleName{joint-sup-static}); a middle union that is not static is the residual case, taken up
below. In the remaining cases the middle witness is constructor-headed. An outer type $\tyAny$ or
$\tyObject$ takes the witness $\tyObject$, above every type, leaving a consistent subtyping
check on the other outer type (\ruleName{joint-sup-any-left}, \ruleName{joint-sup-object-left}). For a
union in an outer position, inversion sends the middle witness below one component, and the witness for the
other component is unconstrained (\ruleName{joint-sup-union-left},
\ruleName{joint-sup-union-right}). A constructor in the middle must head both outer types, or the
case refutes. Tuples proceed componentwise (\ruleName{joint-sup-tuple}); lists and dictionaries
need one element witness equivalent to both element types (\ruleName{joint-sup-list},
\ruleName{joint-sup-dict}); callable arguments need one argument witness above both argument
types, the judgements of \figref{graduality-joint-sub} (\ruleName{joint-sup-callable}), so the two judgements
are mutually recursive.

\input{spec/fig/graduality-joint-sup}

The residual case is a middle union $\tyUnion{\gty{\sigma}}{\gty{\sigma}'}$ that is not static.
Its witness is a union, below a type exactly when both components are, so the two conjuncts become
four constraints, relating each component witness to each outer witness; every witness now appears
in two constraints. The case amounts to the two judgements
$\jointSub{\gty{\sigma}}{\gty{\tau}}{\gty{\sigma}'}$ and
$\jointSub{\gty{\sigma}}{\gty{\tau}'}{\gty{\sigma}'}$ with the witnesses for $\gty{\sigma}$ and
$\gty{\sigma}'$ shared between them, a cycle of four constraints, which no one judgement
expresses. Splitting the union instead, with one judgement per component, is unsound:
$\jointSup{\tyList{\tyAny}}{\tyList{\tyInt}}{\tyList{\tyAny}}$ and
$\jointSup{\tyList{\tyAny}}{\tyList{\tyStr}}{\tyList{\tyAny}}$ hold, but
$\jointSup{\tyList{\tyAny}}{\tyUnion{\tyList{\tyInt}}{\tyList{\tyStr}}}{\tyList{\tyAny}}$ needs
an element witness equivalent to both $\tyInt$ and $\tyStr$.

Sharing the pair of component witnesses suggests a judgement over four gradual types, but the
widening does not stop there: a union in an outer position then sends each component witness below one of its components
independently, so the constraints no longer relate every pair. The
general form is a finite set of subtyping and equivalence constraints over shared witnesses, a
constraint system in the sense of \citet{garcia2015}; its treatment, with the characterisation
of $\jointEquiv{\gty{\tau}}{\gty{\sigma}}{\gty{\tau}'}$, is deferred.
