Type arguments for $\seq{\alpha}$ at which $\seq{\sigma}$ is instantiated to fit $\seq{\tau}$. Each type
argument is the join of the types to which the type parameter is constrained, so the instantiation is the least
under the constraints; the type arguments are undefined if a type parameter does not occur in any pair. Single types
$\sigma$ and $\tau$ stand for sequences of length one.
