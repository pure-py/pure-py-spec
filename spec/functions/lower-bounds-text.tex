Lower bounds on the type variables of $\sigma$ from a type $\tau$ at which $\sigma$ is to be instantiated, as a
sequence of pairs in the order found, each pairing a type variable with the type at the corresponding position of
$\tau$. A type variable is bounded by the base type of $\tau$; a union $\tau$ bounds by each disjunct; lists, dictionaries,
tuples and callables are taken componentwise; an instantiated class is taken through the instance of the class at
$\tau$ (\figref{instance}); and a union $\sigma$ contributes nothing when $\tau$ is below one of its disjuncts, as
\pyinline{None} is below \pyinline{T | None}, and otherwise bounds by each disjunct. In every other case, in particular for a type without type variables, the sequence
is empty. Positions are covariant (tuple components and \pyinline{Callable} results), contravariant
(\pyinline{Callable} parameters) or invariant (list, dictionary and class arguments), following the subtyping rules
(\figref{subtyping}). The type argument chosen for a type variable must accordingly be a supertype, a subtype or an
equivalent of the bound, which the argument check of the \ruleName{call} rule enforces once the type arguments are
chosen.
