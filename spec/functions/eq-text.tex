Structural equality: literals by value\added{, an integer and a float by exact numeric value, so that \pyinline{1 == 1.0} and \pyinline{0.0 == -0.0}}, lists and tuples by their elements, dictionaries with the same
keys by their values, and objects of the same class by their field values, each through $\eqElems{\Sigma}$, except ranges,
which are compared by their sequences, so that \pyinline{range(0, -1) == range(0, -2)}. Any other pair of values is unequal, except that equality is undefined between two functions and between two \replaced{NaNs}{\pyinline{nan} values } in a container, which Python compares by identity, and between a Boolean and a number, which Python compares numerically. Compared directly, two \replaced{NaNs}{\pyinline{nan} values } are unequal in both languages (\figref{run-time-overloads}).
Dictionaries are compared in the entry order of the left operand.
