Structural equality: literals by value, numbers by converting to extended reals, lists and tuples by their elements, dictionaries with the same
keys by their values, and objects of the same class by their field values, each through $\eqElems{\Sigma}$, except ranges,
which are compared by their sequences, so that \pyinline{range(0, -1) == range(0, -2)}. Any other pair of values is unequal, except that equality is undefined between two functions and between $\nan$ and $\nan$ in a container, which Python compares by identity, and between a Boolean and a number, which Python compares numerically. Compared directly, $\nan$ is unequal to itself in both languages (\figref{run-time-overloads}).
Dictionaries are compared in the entry order of the left operand.
