Type variables of $\tau$ which must be instantiated at equality types for an instance of $\tau$ to be an equality type, or $\top$ if $\tau$ is not an equality type at any instantiation; for a class $C$, the type parameters of $C$ at which structural equality on its instances compares values, or $\top$ if a field of $C$ has a type which is not an equality type at any instantiation. A union with $\top$ is $\top$. The case for a class and the case for an instantiated class refer to each other, and the type of a field can mention its own class through a type alias, so the cases are not a definition by recursion: $\eqVars{\Sigma}$ is the least function satisfying them, with sets ordered by inclusion and $\top$ above every set. A class therefore compares a type parameter, or has value $\top$, only when one of its fields requires it.
