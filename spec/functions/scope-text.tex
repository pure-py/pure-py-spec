Context for the body $s$ of a function with parameters $Y$, or of a module with imported names $Y$, in which each variable declared or assigned in $s$ is unbound and the names in $Y$ keep their bindings. Undefined if $s$ declares a name twice or declares a name in $Y$, or if a pattern in $s$ binds a name declared in $s$ or in $Y$. The context serves as an environment as well, $\Unbound$ being a value as well as a context entry.
