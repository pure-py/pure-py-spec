Context for the body $s$ of a function with parameters $\seq{y}$, or of a module with imported names $\seq{y}$, in which each variable declared or assigned in $s$ is unbound and the names in $\seq{y}$ keep their bindings. Undefined if the names $\seq{y}$ are not distinct, if $s$ declares a name twice or declares a name in $\seq{y}$, or if a pattern in $s$ binds a name declared in $s$ or in $\seq{y}$. The context serves as an environment as well, since $\Unbound$ is a value as well as a context entry.
