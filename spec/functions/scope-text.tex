\added{Context in which each variable declared or assigned in $s$, the body of a scope, is unbound. Defined if and only if the names declared in $s$, the names in $Y$ and the pattern variables of $s$ are pairwise distinct, where $Y$ is the set of parameters of a function or of imported names of a module. The context serves as an environment as well, $\Unbound$ being a value as well as an entry.}
