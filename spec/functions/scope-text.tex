Context for the body $s$ of a function with parameters $\replaced{\seq{y}}{Y }$, or of a module with imported names $\replaced{\seq{y}}{Y }$, in which each variable declared or assigned in $s$ is unbound and the names in $\replaced{\seq{y}}{Y }$ keep their bindings. Undefined if \added{$\seq{y}$ has a repeat, if }$s$ declares a name twice or declares a name in $\replaced{\seq{y}}{Y }$, or if a pattern in $s$ binds a name declared in $s$ or in $\replaced{\seq{y}}{Y }$. The context serves as an environment as well, $\Unbound$ being a value as well as a context entry.
