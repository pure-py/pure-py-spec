Environment bound by an import prefix $\seq{\iota}$, given the environments $\mathcal{L}$ of the loaded modules. A plain
import binds its first name to a loaded module value whose environment is extended by its submodules along the chain,
and a from-import binds each imported name to the member of that name, or to a loaded module value if the member is
a submodule. Both mirror the import rules of \figref{typing-import-prefix}.
