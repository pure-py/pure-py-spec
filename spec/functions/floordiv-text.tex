Floor division of float $n$ by nonzero float $n'$, following the Python Language Reference (\S6.7, note~2), which returns the quotient of $n - (n \mathbin{\pyinline{\%}} n')$ by $n'$ when rounding would make the floor of the quotient one larger: the exact truncated remainder $n_1$ is subtracted from $n$, the difference divided by $n'$, the result decreased by one if $n_1$ and $n'$ have opposite signs, and rounded to the nearest integer, halves down. An infinite $n_3$ is the result, and a zero result takes the sign of $n / n'$. This is the algorithm of CPython, with which it agrees on all values.
