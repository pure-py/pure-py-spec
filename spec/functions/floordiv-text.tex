Floor division of float $n$ by nonzero float $n'$, with the algorithm of the Python Language Reference, \S6.7, note~2. For finite $n$ and $n'$, let $n_1 = n - (n' \times \trunc(n / n'))$, the remainder of truncated division computed exactly, $n_2 = \fl(\fl(n - n_1) / n')$, and $n_3 = \fl(n_2 - 1)$ if $n_1 \neq 0$ has the opposite sign to $n'$, and $n_2$ otherwise.
