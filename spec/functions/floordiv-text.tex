Floor division of float $v$ by nonzero float $v'$, following the Python Language Reference (\S6.7, note~2), which returns the quotient of $v - (v \mathbin{\pyinline{\%}} v')$ by $v'$ when rounding would make the floor of the quotient one larger: the exact truncated remainder $m$ is subtracted from $v$, the difference divided by $v'$, the result decreased by one if $m$ and $v'$ have opposite signs, and rounded to the nearest integer, halves down. An infinite $d'$ is the result, and a zero result takes the sign of $v / v'$. This is the algorithm of CPython, with which it agrees on all values.
