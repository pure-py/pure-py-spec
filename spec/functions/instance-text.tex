Instantiation of class $C$ comparable with type $\tau$, when there is one up to equivalence: the class of the
values of $\tau$ matched by a constructor pattern naming $C$, whose type arguments the pattern cannot
supply. Undefined when no instantiation is comparable with $\tau$, so that no value of $\tau$ matches, and
when several are, as for a class with type parameters at \tyObject, whose type arguments $\tau$ does not
determine.
