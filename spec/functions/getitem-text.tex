Subscripting: the value under key $v'$ of a dictionary, or the element at index $v'$ of a sequence,
counting from the end when the index is negative. Aborts with $\errKey$\replaced{ or}{,}
$\errIndex$ \deleted{or $\errType$ }when Python raises the exception of that name\added{. Aborts with $\errExcluded$ in three cases which Python allows but no typing rule for subscripts accepts: a range subscripted at all, a sequence indexed by a Boolean, which Python treats as the integer 0 or 1, and a dictionary subscripted by a key other than a string (\secref{operational-semantics}). Aborts with $\errType$ for any other pair of values}\deleted{, and with $\errType$ for a dictionary subscripted by a value other than a string}.
