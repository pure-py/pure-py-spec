Subscripting: the value under key $v'$ of a dictionary, or the element at index $v'$ of a sequence,
counting from the end when the index is negative. Aborts with $\errKey$,
$\errIndex$ or $\errType$ when Python raises the exception of that name\added{, and with $\errExcluded$ for a dictionary subscripted by a key other than a string, where Python raises \pyinline{KeyError}, or \pyinline{TypeError} for a key which it cannot hash, and for a range subscripted by any value, since Python indexes a range as a sequence}\deleted{, and with $\errType$ for a dictionary subscripted by a value other than a string}.
