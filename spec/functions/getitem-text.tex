Subscripting: the value under key $v'$ of a dictionary, or the element at index $v'$ of a sequence,
counting from the end when the index is negative. Aborts with $\errKey$,
$\errIndex$ or $\errType$ when Python raises the exception of that name\added{, so a dictionary subscripted by a key other than a string aborts with $\errKey$ when the key is hashable and with $\errType$ otherwise, and a range subscripted by any value aborts with $\errExcluded$, since Python indexes a range as a sequence}\deleted{, and with $\errType$ for a dictionary subscripted by a value other than a string}.
