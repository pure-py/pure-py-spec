Subscripting: the value under key $v'$ of a dictionary, or the element at index $v'$ of a sequence,
counting from the end when the index is negative. Aborts with $\errKey$,
$\errIndex$ or $\errType$ when Python raises the exception of that name\added{, and with $\errExcluded$ for any attempt to subscript a range, since no subscript rule applies to ranges, although Python allows it, and for dictionaries subscripted by keys other than strings, although Python raises \pyinline{KeyError}, or \pyinline{TypeError} for keys it cannot hash, since \PurePy has no notion of hashing and cannot distinguish the two}\deleted{, and with $\errType$ for a dictionary subscripted by a value other than a string}.
