Subscripting: the value under key $v'$ of a dictionary, or the element at index $v'$ of a sequence,
counting from the end when the index is negative. Aborts with $\errKey$,
$\errIndex$ or $\errType$ when Python raises the exception of that name\added{, and with $\errExcluded$ for any attempt to subscript a range, which Python indexes as a sequence, and for a dictionary subscripted by a key other than a string, although Python raises \pyinline{KeyError}, or \pyinline{TypeError} for keys which it cannot hash, since the \PurePy semantics treats all such keys alike}\deleted{, and with $\errType$ for a dictionary subscripted by a value other than a string}.
