The comparisons \pyinline{==}, \pyinline{!=}, \pyinline{in} and \pyinline{not in} are given in terms of
structural equality $\eqOp$ and membership $\memOp$. Where defined, the
operators agree with Python, yielding $\aborts{\kappa}$ where Python raises an
exception. Where undefined, evaluation of the expression has no derivation: the operation has a meaning in
Python that \PurePy does not adopt\paperonly{ (\secref{no-coercions})}, and an implementation may abort or
produce Python's result (\paperonly{\secref{python-compatibility}}\speconly{\secref{conformance}}). Because
equality is partial, the order in which elements are compared is observable: equality and membership stop
at the first element that decides the result, so an undefined comparison later in a sequence does not make
the whole undefined.
