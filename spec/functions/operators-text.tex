Where they are defined, the operators, structural equality and membership have the meanings they have in
Python, yielding $\aborts{\kappa}$ where Python raises. Each is undefined where no case applies, and an
expression applying an undefined operation has no derivation; these are the cases where \PurePy declines
to give the operation the meaning Python gives it, a non-Boolean test being
another\paperonly{ (\secref{no-coercions})}. Because
equality is partial, the order in which elements are compared is observable: equality and membership stop
at the first element that decides the result, so an undefined comparison later in a sequence does not make
the whole undefined.
