Result of matching pattern $p$ against value $v$ under environment $\rho$: the bindings of the pattern
variables if $p$ matches $v$, and $\noMatch$ if it does not. The result is $\errUndef$ for a numeric literal pattern if the equality of the literal and the value is undefined. A Boolean literal pattern does not match a number, since Python compares the value with the literal by identity. Sub-patterns are matched left to right, their results composing with $\override$
(\secref{eval-patterns}).
