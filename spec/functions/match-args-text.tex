Type arguments for the type variables of $\rho$, found by one-way matching of $\rho$ against $\sigma$ and given as a
context binding type variables at types, or for a sequence $\seq{\rho}$ against $\seq{\sigma}$. A type variable in $\rho$ is
bound to the type at the same position in $\sigma$. A union in $\rho$ does not bind any type variable. Lists,
dictionaries, tuples, callables and instantiations of one class are matched componentwise, and the contexts given by
the components are composed by $\override$. Two equal types match with the empty context. The clauses apply in
order. The matching is undefined in every other case, such as a type variable or union in $\sigma$ at the position
of a type of another form in $\rho$, and is undefined for a sequence if it is undefined for a component. The
instance of a class below an instantiation of one of its base classes is found by matching
(\ruleName{instance-below}).
