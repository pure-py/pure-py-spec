Some rules reject programs that \PurePy could otherwise accept, so that a well-typed program is also well typed
under mypy (\secref{well-formedness}), and \figref{mypy-restrictions} lists them with the rule that enforces each.
In particular, the narrowing of a match scrutinee follows mypy, because the typing specification leaves narrowing
largely unspecified.\footnote{\url{https://typing.python.org/en/latest/spec/narrowing.html}}
