Python accepts several implicit coercions and lax matches. \figref{coercions} lists those excluded by
\PurePy and records at which stage each exclusion takes effect. \added{The figure also lists operations with an outcome which is not specified by the Python language reference and which differs between implementations.} A program which reaches a dynamically excluded operation runs under Python but has undefined behaviour under
\PurePy. A run which reaches a statically excluded operation aborts with $\errExcluded$ (\secref{operational-semantics}); such runs are ruled out by type soundness (\secref{type-soundness}).
