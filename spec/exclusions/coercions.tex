Python accepts several implicit coercions and lax matches. \figref{coercions} lists those excluded by
\PurePy, and records at which stage each exclusion takes effect. A program which reaches a dynamically excluded operation runs under Python but has undefined behaviour under
\PurePy. A run which reaches a statically excluded operation aborts with $\errExcluded$ (\secref{operational-semantics}), so
that it can be ruled out by type soundness (\secref{runtime-errors}).
