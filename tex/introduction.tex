\section{Introduction}

\begin{itemize}
\item Define subset of Python called \PurePy, defined as a syntactic subset further restricted by a
well-formedness predicate
\item Define a semantics for \PurePy such that the semantics of a \PurePy program is identical to its
semantics in Python
\item Some well-formedness and evaluation rules could be given by a desugaring, but for now we avoid having
two separate syntaxes
\end{itemize}

Python interoperability is a key goal, but \PurePy is also motivated by the desire to carve out a well-behaved
discipline for scientific programming \emph{within} Python: a sublanguage in which permissive Python idioms
that invite confusion are tightened or excluded.
