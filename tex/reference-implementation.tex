\section{Reference implementation}
\label{sec:reference-impl}

A reference checker, written in Python over the \pyinline{ast} module, decides well-formedness and
reports why a program is rejected. This section describes the checker and its correspondence with the
well-formedness rules of \secref{well-formedness}.
